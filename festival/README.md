## 何ができるアプリか（3行）

上から猫のボールを落として、同じ種類の猫がぶつかると合体し、ひとまわり大きい猫に変わる「落ち物合体パズル」です。

猫は全部で10段階あり、10段階目の「伝説の最強猫」ができたらクリアです。赤い点線より上にボールが合計5秒はみ出すと負けになります。

1%の確率で「？」ボールが出てきて、6匹の犬のルーレットで、いいことか悪いことが起きます。

## 画面

1. **箱の中のボール**

   丸いボールの中に猫ミームの写真が入っていて、ふちの色が猫ごとにちがいます（cat1 はピンク、cat2 はオレンジ、cat3 は赤 …）。大きい猫ほどボールも大きくなります（直径 56 〜 220）。

2. **「？」ボールとルーレット**

   虹色の「？」のボールです。落とすと画面のまん中にルーレットが出て、6匹の犬（当たり3匹・はずれ3匹）の中から1匹が決まります。

3. **合体・アイテムの演出**

   合体すると音と猫の声が鳴り、cat8・cat9 ができたときはお知らせが出ます。シャッフル（突風）のときは、白い線が下から上へふき上がります。

4. **危険ライン**

   赤い点線より上にボールがあると「危険！ラインの上にボールが！あと○秒」と出て、0秒になると「GAME OVER」になります。

## 使った文法・技術

- 構造体 Fruit（箱の中のボール1個分：レベル・位置・速さ・何かに当たったか）と、その配列 [Fruit]
- for の二重ループ（箱の中の全部のボールの組み合わせを調べる）
- 2つの円の距離の計算（x と y の差を2乗して足し、半径の合計の2乗と比べる）
- Timer.publish で 1/60 秒ごとにボールを動かす
- 重力・空気抵抗・床のまさつ・はね返りを数字で決めた物理演算（BallPhysics）
- 配列の remove(at:) と append（2つのボールを消して、大きいボールを1つ足す）
- contains（ラインより上にはみ出したボールがあるか調べる）
- 重みつきの乱数（Double.random を使い、小さい猫ほど出やすくする）
- enum Game の中に、設定の数字を static let でまとめる
- AVFoundation の AVAudioPlayer と、辞書 [String: AVAudioPlayer]（一度作ったプレイヤーを使い回す）
- Bundle.main.url（アプリに入れた mp3 を名前で探す）
- Image("cat1") のように、Assets に入れた画像を名前で表示する

## 生成AIの使い方（どの場面で、どう使ったか）

- ボールが落ちて、ぶつかって、合体するところ（物理演算と衝突判定）は、自分たちで一から書くのはむずかしかったので、生成AIに書いてもらいました。
- 猫ミームの画像と鳴き声は自分たちで集めて、ファイル名を cat1 〜 cat10 にそろえました。そのうえで、AIに「同じ名前の画像と音声を読みこむ」形にしてもらったので、猫を入れかえるときはファイルを差しかえるだけですみました（cat6 は途中で新しい子猫に変えました）。
- 遊んでみると、大きい猫（cat7・cat8）が出すぎて簡単すぎたので、AIに相談して出やすさの数字を下げてもらいました。
- 衝突判定のコードは、AIに「この計算は何をしていますか」と質問して、1行ずつ意味を確かめました。

## 展示で工夫した点

- 猫ごとにちがう鳴き声が出るので、落とすだけで楽しいです。速く落としても声が何重にも重ならないように、前の声を止めてから次を鳴らします。cat5 の声は大きすぎたので、音量を半分にしました。
- ボールのふちの色を猫ごとに変えて、どれとどれが同じ猫か、ぱっと見て分かるようにしました。
- はじめの5個は一番小さい2種類しか落ちてこないので、はじめて遊ぶ人もすぐに合体を体験できます。同じ猫が4回以上続けて出てこないようにもしました。
- 落ちている途中のボールは危険ラインの判定に入れないので、「何もしていないのに負けた」ということになりません。
- iPhone の画面の大きさに合わせてボールの大きさを自動で変えるので、小さい iPhone でも大きい iPhone でも、同じくらいの難しさで遊べます。
- 1%の「？」ボールが出るとルーレットが回るので、まわりで見ている人ももり上がります。
